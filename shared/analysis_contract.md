# 数据与交付约束（优先于历史提示词中的冲突说明）

所有 command、coordinator、分析/审计角色先读本文件。§1–§17 段号与原有参数名保持兼容；无法验证的字段用 `null/未核实`，不得为满足模板而编造。

## 确定性数据

- 同一次分析使用采集器生成的 `data_pack_market.md`、`data_snapshot.json`、`decision_metrics.json`；估值引擎从同一快照读取，不独立换一批行情。
- `--refresh-market` 强制刷新行情、按TTL重载财报并重新计算§17；财务时效看“财务采集时间”，不能用行情刷新时间替代。
- 原始三表金额为元，Markdown数据包为百万元，正文为亿元。每股数值为元/股，不能混用。
- 比较数据必须标明报告期、合并/母公司、公告版本。中报/三季报通常为年初累计；不等于单季或全年。跨表期间/重述版本未对齐时，不输出复合估值。
- 分红按财政年度汇总中期+末期。须有已实施的末期方案、过去的实施日期，且无未实施方案，才算完整年度；前一年也可能未完整。不能把最新单次派息或当年中期当全年。
- M优先用完整年度、各次分红股本计算的归母分红总额/归母净利润。DPS/EPS为近似交叉检验。现金流“分配股利、利润或偿付利息”含利息/少数股东且属于支付年度，不可替代M、不可反推DPS。DPS连续相同不自动构成错误。
- D&A按同年度补充，东财同类折旧字段不能重复相加；缺项不按0。营业利润+带符号财务费用+D&A仅为EBITDA近似值。
- §17.5默认AA是合并OCF−全部Capex的**参考代理**；旧的“营业成本+员工现金”重建可能重复扣减，仅供诊断。归母/少数股东、受限现金、一次性项目未穿透前，不能称为已验证归母可分配现金。
- 未核对FCFF/FCFE及利息、税盾、营运资本、少数股东时，DCF标“不适用”，不能硬套WACC。负增长Gordon可数学收敛，但不能把周期下降直接当永续事实；DDM显示前5年与终值假设，终值默认0%只是情景，不是预测。
- 需要恢复母公司表、审计意见、已核对归母现金或FCFF时，使用`shared/financial_supplement_schema.md`定义的来源补充；逐项附原文位置，采集器验证期间/单位和底表一致性。不得靠手改decision_metrics.json把unverified改成verified。
- 历史PE必须未复权价格对同期EPS；PS使用同期股本，不能用当前股本回填历史。多法历史参考价不是保底价，非正/缺失方法排除，少于3项不合成。
- G不进入R/GG公式。§17网格只选行，不手算。未经来源核对的数值不能通过LLM“调整”变为已核实数据。

## PDF与审计

- 先用 `pdf_preprocessor.py --text-output ... --full-text`，读摘要，再按需读全文分片和manifest定位页码；需要表格核对时再看原PDF。
- P2受限资产、P3应收账龄、P4关联交易、P6或有负债与承诺、P13非经常性损益。关键词命中不是整章阅读，生成全文不等于已读全文。
- 扫描/乱码/空文本必须标“需OCR/外部来源补充”。现有预处理器不具备OCR；不可重跑文本提取后声称扫描件已解析。
- 母公司报表只使用明确母公司来源；缺失时年报补充须写报告期、页码、单位。审计意见须有年报或公告来源，缺失为“未核实”，不是通过。
- clean-room保持独立输入；numeric_audit通过且有实际产物后，才可称“完整流程已完成”。报告类型不同使用相应gates；正则冲突提示是advisory，不可假装完整财务审计。
- numeric_audit结束前用`shasum -a 256 <report> <decision_metrics.json>`取当前文件哈希，在审计末尾分别写独立行`REPORT_SHA256: <hash>`与`METRICS_SHA256: <hash>`。修改报告/数据后须重新审计；不能复用上期PASS。完整流程同时用`--require-cleanroom <dir>/cleanroom_metrics.md`检查独立重算产物。BA的audit.md不等于最终策略报告的审计；最终策略/估值报告分别生成final_audit.md/valuation_audit.md。

## 报告与决策卡

- 第一屏保留七项投资决策卡。纯定性报告、数据缺失或模型不适用时，买价/回调写“未估值/待核实”；不要为填写决策卡临时发明买点。
- 只有 `decision_metrics.json` 中已核实的目标价才可直接进入买点栏；参考情景不能冒充投资指令。买点、M、R、税率及AA版本必须一致。
- R低于Rf/II是评估结果，不自动终止分析，不得擅自声称触发框架否决门。数据不可用时可以交付边界清晰的降级报告，不可交付确定买卖/持有结论。
- 禁止保证盈利、保证本金安全等措辞。持有建议须说明成本、仓位、期限等适用条件；缺少个人信息时只列复核项目。
- 更新现有报告必须含“较上期变化”，包括撤销失效价格/评级的原因；文件不加日期后缀，正文写日期。默认只交付Markdown，HTML仅用户明确要求时生成。
- OpenCode继承当前会话模型。运行前确认实际provider/model并在报告记录；未指定/不可确认时不得声称使用GLM或特定模型。提示词伪代码的Agent/Task/Bash映射到当前OpenCode可用工具，不能使用不存在的工具或虚构执行结果。
